Campo Contenido
CU-02 Registrar Usuario
Actor Administrador
Descripción Permite dar de alta a un nuevo empleado de la financiera en el sistema, asignándole sus credenciales iniciales de acceso.
Precondición * El usuario administrador debe estar autenticado en el sistema.
* El empleado a registrar no debe poseer una cuenta previa activa con el mismo identificador único o legajo en la base de datos.
Postcondición El nuevo usuario es persistido en la base de datos relacional en estado "Activo", quedando disponible para la asignación de roles y la posterior autenticación operativa.
Secuencia normal
Paso Acciones del usuario Respuesta del sistema
1 El administrador selecciona la opción "Registrar Usuario" desde el panel de administración de personal.
2 El sistema renderiza el formulario de alta solicitando los datos obligatorios: Nombre, Apellido, DNI/Legajo, Correo Electrónico, Nombre de Usuario y Contraseña inicial.
3 El administrador completa los campos del formulario con la información del nuevo empleado y presiona el botón "Guardar".
4 El sistema realiza las validaciones de integridad de los datos, cifra la contraseña de forma segura, persiste el registro del nuevo usuario en la base de datos con estado "Activo", asienta la acción en el log de auditoría y muestra un mensaje de confirmación exitosa.
5 El administrador visualiza el mensaje de éxito y el nuevo registro en el listado general de usuarios de la plataforma.
Excepciones
Paso Fallo / Condición Acción del sistema
Paso 4 El identificador único (Nombre de Usuario o Legajo/DNI) ya se encuentra registrado en el sistema. El sistema interrumpe la persistencia, resalta el campo duplicado y muestra el mensaje de error: 'El nombre de usuario o legajo ya se encuentra registrado en el sistema.'.
Paso 4 Se detectan campos obligatorios vacíos o el formato del correo electrónico es inválido. El sistema detiene el proceso, marca las alertas de validación en los campos correspondientes del frontend y muestra el mensaje: 'Por favor, complete todos los campos obligatorios con formatos válidos.'.
Estabilidad Alta
Comentarios * El alta inicial de la cuenta se realiza por defecto en estado "Activo", pero requiere de forma complementaria la ejecución de CU-05 (Asignar Roles y Permisos) antes de que el nuevo empleado pueda operar los módulos del negocio.
* Todas las contraseñas guardadas en la base de datos son procesadas mediante funciones de hash seguras provistas por el framework CodeIgniter 4.
